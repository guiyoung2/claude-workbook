# 심층 인터뷰 (Deep Interview)

## 핵심 접근법

불명확한 요청을 즉시 실행하는 대신, 명확한 명세로 체계화한다. 핵심은 가장 큰 불확실성을 하나 선택하고, 암묵적 가정과 의사결정 기준을 드러내는 소크라테스식 질문을 통해 한 번에 하나씩 해결하는 것이다.

## 질문 축 (우선순위 순)

- 목표
- 범위 및 제외 사항
- 제약 조건
- 완료 기준
- 기존 맥락 및 영향 범위

코드베이스 검사로 답을 얻을 수 있는 경우, 사용자 질문 대신 직접 확인으로 대체한다.

## 프로세스

턴당 하나의 질문만 한다. 각 질문에는 현재 이해도, 핵심 불확실성, 추천 답변(가능한 경우)을 제시한다.

질문 템플릿:
```md
현재 이해도: {한 문장 요약}
핵심 불확실성: {주요 불확실 사항}
추천 답변: {가능한 경우}
질문: {단일 질문}
```

응답 후 결정 사항을 업데이트하고, 중요한 불확실성이 남아있는 경우에만 계속한다.

## 종료 기준

다음이 정의되면 종료한다:
- 목표
- 포함 및 제외 범위
- 유지해야 할 제약 조건
- 완료 판단 기준
- 남아있는 미결 사항

전체 대화 이력 대신 결정 사항과 미결 사항 요약을 제공한다.
