`/last30days`는 Reddit, X, YouTube, Hacker News, Polymarket, GitHub, 웹 등 여러 소스를 병렬로 최근 기간에 맞춰 조사하고, engagement·인용·출처를 바탕으로 하나의 grounded brief로 합성하는 Agent Skill입니다. Agent Skills CLI로 Codex, Cursor, Copilot, Gemini CLI 등 50개 이상 host에 설치할 수 있는 portable skill이면서, Claude Code·Codex용 native plugin manifest도 함께 제공합니다.

## 왜 필요한가

일반 검색은 editor나 SEO 중심 결과를 주지만, 사람들이 실제로 최근에 어떻게 반응했는지는 잘 보여주지 않습니다. last30days는 upvote, like, 댓글, 조회수, prediction-market odds, GitHub 활동처럼 사람이 실제로 반응한 신호를 수집·점수화해 "최신 사실을 하나 찾기"보다 여러 조각을 최근 맥락으로 엮는 데 맞춰져 있습니다.

- 미팅 전 인물·회사·제품의 최근 활동 조사
- 새 기술·AI tool·문화 현상의 급상승 신호 탐색
- 경쟁 도구 비교 및 최근 release·issue·community 반응 요약
- 여행·채용·브랜드·시장 관련 최근 커뮤니티 신호 조사

기본적으로 Reddit, HN, Polymarket, GitHub는 zero-config로 작동하며, 첫 실행 setup wizard를 통과하면 X, YouTube, TikTok, arXiv, Techmeme 등 추가 소스를 활성화할 수 있습니다. 일부 소스는 API key, 로그인 browser cookie, 로컬 CLI 또는 별도 서비스가 필요합니다.

## 설치 방법

### Claude Code: 권장 marketplace 설치

```text
/plugin marketplace add mvanhorn/last30days-skill
/plugin install last30days
```

README는 marketplace가 versioned plugin cache와 auto-refresh를 처리하므로 이 방식을 권장합니다. 업데이트 확인은 다음 명령을 사용합니다.

```bash
claude plugin update last30days@last30days-skill
```

Claude Code에서 Agent Skills CLI 설치를 함께 쓸 수도 있지만, marketplace plugin과 `npx skills` 사본을 동시에 켜면 `/last30days`가 두 개 나타날 수 있습니다. 한 기기에서는 설치 방식 하나만 사용해야 합니다.

### Codex: Agent Skills CLI

글로벌 설치:

```bash
npx skills add mvanhorn/last30days-skill -g -a codex
```

프로젝트에만 설치하려면 `-g`를 뺍니다. 업데이트·목록·제거는 다음과 같습니다.

```bash
npx skills update last30days -g
npx skills list -g
npx skills remove last30days -g
```

처음 조사하기 전에는 불러온 skill directory에서 preflight를 실행하는 것이 좋습니다. Preflight는 cookie를 읽거나 파일을 쓰거나 실제 조사를 실행하지 않고, config source·cookie 계획·예정된 write·선택 명령을 보여줍니다.

```bash
python3 skills/last30days/scripts/last30days.py --preflight
```

## 사용 흐름

```text
/last30days <인물·회사·주제·비교 대상>
```

스킬은 먼저 올바른 handle, subreddit, hashtag, GitHub identity를 찾는 pre-research를 수행한 뒤 소스별 결과를 모으고, 중복 cluster를 병합해 brief를 만듭니다.

- `--hiring-signals`: 채용 공고·careers page를 근거로 최근 채용 방향을 관찰 가능한 signal로 읽는다.
- 비교 질문: 여러 tool을 단일 조사로 대조해 architecture·security·best-for 등을 표로 합성한다.
- discovery 질문: Reddit, HN, Digg, 인증된 X 등을 훑어 engagement velocity 기준의 후보 주제를 제시한다.
- `--as-of`: 과거 기준 시점의 lookback을 지원한다.
- `--emit=html`: self-contained HTML brief를 만든다.
- `--diagnose`: key 누락, PATH에 없는 CLI, 만료된 cookie처럼 소스가 빈약한 원인을 점검한다.

## 소스와 접근 요구사항

| 범주 | 예시 소스 | 특성 |
| --- | --- | --- |
| 기본 zero-config | Reddit, Hacker News, Polymarket, GitHub | API key 없이 즉시 쓸 수 있는 기본 조사층이다. |
| 소셜·영상 | X, YouTube, TikTok, Instagram Reels, Threads, Bluesky | 최신 반응과 transcript를 넓히지만 인증·cookie·provider 설정이 필요할 수 있다. |
| 기술·연구 | arXiv, Techmeme, Digg, Perplexity | 논문·editorial layer·AI account cluster·grounded synthesis를 보완한다. |
| 전문·시장 | LinkedIn, StockTwits, Pinterest, Xiaohongshu | 주제와 지역에 따라 유용하지만 별도 조건 또는 opt-in 경로가 있다. |
| 웹 | 일반 web search | 여러 signal 중 하나이며, 유일한 진실 원천으로 두지 않는다. |

engagement가 높다는 것은 특정 공동체의 관심을 뜻할 뿐 사실성, 대표성, 장기적 중요성을 보장하지는 않습니다.

## 언제 쓰면 좋은가

- 최근 며칠~한 달의 빠른 변화와 community reaction이 중요한 질문
- 공식 문서뿐 아니라 사용자 불만, 사용 패턴, 영상 설명, prediction signal을 함께 보고 싶은 경우
- 여러 source를 직접 탭으로 열어 비교하기 전에 broad research brief가 필요한 경우
- 인물·회사 미팅, 경쟁 분석, 새 제품 조사, 시장/문화 동향 탐색을 준비할 때

## 주의할 점

검색 결과의 인용과 timestamp를 확인한 뒤 중요한 주장에 사용해야 합니다. 이 스킬의 summary는 출발점이지 고위험 의사결정의 최종 검증이 아닙니다. X·YouTube 등 인증 source를 쓰려면 browser cookie나 API credential에 접근할 수 있으므로, preflight와 setup wizard에서 읽는 범위·저장 위치·cookie 만료 정책을 먼저 확인해야 합니다. 소셜 engagement는 조작, echo chamber, 지역 편향, 선정성의 영향을 받을 수 있어 "사람들이 많이 반응했다"와 "사실이다"를 동의어로 쓰면 안 됩니다. 30일 window가 모든 질문에 적절한 것은 아니며, 역사적 배경·안정된 기술 사실·법·의학·금융 판단은 1차 출처와 더 긴 시간 범위를 추가해야 합니다.

## 한 문장으로 정리

last30days는 하나의 검색 API가 아니라, 서로 닫혀 있는 여러 소스를 병렬로 수집하고 engagement-aware 방식으로 합성해 인용 가능한 최근 신호 브리프를 만드는 리서치 워크플로입니다.
