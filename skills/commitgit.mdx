## 개요

`commitgit` 스킬은 Claude Code에서 git 커밋과 푸시 작업을 체계적으로 진행하는 워크플로우를 제공합니다. 변경 사항 확인부터 컨벤션에 맞는 메시지 작성, 실제 커밋까지 모든 단계를 안내합니다.

---

## 워크플로우 단계

```
1. git status → 변경 파일 목록 확인
2. git diff   → 변경 내용 상세 검토
3. git log    → 기존 커밋 스타일 파악
4. 커밋 메시지 초안 생성 (컨벤션 적용)
5. 사용자 확인 → git add + git commit
6. git push   → 원격 브랜치에 반영
```

---

## 사용법

Claude Code 세션에서 아래처럼 입력합니다:

```
/commitgit
```

---

## 커밋 컨벤션

이 프로젝트에서 사용하는 커밋 메시지 형식:

```
<타입>. <한글 설명>
```

| 타입 | 용도 |
|------|------|
| `feat.` | 새 기능 추가 |
| `fix.` | 버그 수정 |
| `refactor.` | 기능 변경 없는 코드 개선 |
| `chore.` | 설정·의존성·빌드 등 비기능 변경 |

### 예시

```
feat. 다크모드 ThemeProvider 및 사이트 헤더 구현
fix. 하이드레이션 불일치로 인한 테마 초기화 오류 수정
refactor. PostCard 컴포넌트 단일 책임 원칙에 맞게 분리
chore. shadcn/ui Tailwind v4 기반 초기화 및 의존성 추가
```

## 안전 규칙

스킬이 자동으로 적용하는 안전장치:

- `--no-verify` 옵션 절대 사용 금지
- force push (`--force`) 전 반드시 사용자 확인
- `.env`, credential 파일은 커밋 대상에서 제외
- 빈 커밋 생성 방지
