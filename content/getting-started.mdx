## Claude Code란?

Claude Code는 Anthropic이 만든 **터미널 기반 AI 코딩 도우미**입니다.
명령줄에서 Claude와 대화하면서 코드를 작성하고, 파일을 편집하고, 명령을 실행할 수 있습니다.

> VS Code 확장이나 웹 에디터가 아닌, 터미널에서 직접 동작한다는 점이 핵심입니다.

## 설치 방법

Node.js 18 이상이 설치된 환경에서 다음 명령을 실행합니다.

```bash
npm install -g @anthropic-ai/claude-code
```

설치 후 `claude` 명령이 PATH에 등록됩니다.

## 첫 실행

프로젝트 폴더로 이동한 후 `claude`를 실행합니다.

```bash
cd my-project
claude
```

처음 실행하면 Anthropic 계정 인증을 요청합니다. 브라우저가 열리면 로그인하면 됩니다.

## 기본 동작 방식

Claude Code는 프롬프트를 입력하면:

1. 현재 디렉터리의 파일 구조를 읽어 컨텍스트를 파악합니다
2. 필요한 파일을 열람하거나 수정 계획을 세웁니다
3. 사용자 승인 후 실제 파일을 편집합니다

직접 파일을 수정하기 때문에 결과물을 복사·붙여넣기할 필요가 없습니다.
