## 슬래시 명령어란?

세션 중 `/`로 시작하는 명령을 입력하면 대화가 아닌 **CLI 동작**이 실행됩니다.
코드 수정 없이 세션을 제어할 때 사용합니다.

## 자주 쓰는 명령어

### /clear

현재 대화 컨텍스트를 초기화합니다. 새 작업을 시작할 때 유용합니다.

```
/clear
```

컨텍스트가 너무 길어지면 Claude의 응답 품질이 떨어질 수 있습니다.
새 주제를 시작할 때는 `/clear`로 리셋하는 것이 좋습니다.

### /help

사용 가능한 명령어 목록을 출력합니다.

```
/help
```

### /compact

대화 기록을 요약해서 토큰을 절약합니다. `/clear`와 달리 컨텍스트를 유지한 채로 압축합니다.

```
/compact
```

### /exit (또는 Ctrl+C)

세션을 종료합니다.

```
/exit
```

## 파일 참조

대화 중 `@파일명`으로 특정 파일을 직접 참조할 수 있습니다.

```
@src/components/Button.tsx 이 컴포넌트에 로딩 상태를 추가해줘
```

Claude가 해당 파일을 읽고 수정 계획을 세웁니다.

## 팁

- 작업이 복잡할수록 먼저 계획을 확인하고(`계획을 먼저 말해줘`) 승인 후 진행합니다
- `!` 접두사로 셸 명령을 직접 실행할 수 있습니다 (`! npm run dev`)
